Use Case 3 — Widget Behaviour Change
A user asks about a widget difference they noticed after migrating from User Hub to CX Dashboard. The AI answers directly from the Confluence knowledge base.
💬 User Question
“In User Hub I see one widget for Calibration, however it is two in CX Dashboard. Can you explain the behaviour?”
🤖 AI-Generated Response
🤖ResolveIQ AI
KB ANSWER
The Calibration widget was redesigned in CX Dashboard. The original single widget (UH) was not time-bound and showed only the last 10 calibrations.

It has been replaced by two new widgets:
1. Evaluators Calibration
Shows variance of evaluators across all calibrations they participated in, within the selected duration. Automatically surfaces the 6 evaluators with the highest variance.
2. Forms Calibration
Same as above, but grouped by form instead of evaluator.
Configurable duration: Last 7 / 30 / 90 days · Custom range (up to 90 days) · Default: last 90 days
